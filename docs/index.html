artemis-design

principles

Flat and minimal. No gradients, shadows or rounded corners (except the status dot). 1px hairlines for structure. Mono for labels and data, sans for UI, serif italic for quotes only. Hierarchy comes from text color (text → muted → dim), not weight. One accent color, used only for status.

install

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jkotra/artemis-design@v0.1.0/dist/artemis.min.css">

Or copy dist/artemis.min.css into your project. Set data-theme="light" on <html> for the light theme.
